# CineScope

Персональная платформа для поиска фильмов и сериалов с каталогом, личной библиотекой, историей просмотров и подбором по настроению.

## Запуск локально

**Требования:** Node.js (>= 18)

1. Установите зависимости:
   `npm install`
2. Настройте API-ключи в [.env](.env) (или запустите без них в Demo Mode)
3. Запустите приложение:
   `npm run dev`
4. Откройте в браузере: [http://localhost:3000](http://localhost:3000)
